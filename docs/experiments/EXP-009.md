# EXP-009 — Order Sensitivity on Near-Duplicate Surfaces (follow-up to EXP-001)

**Status:** preregistered and approved (2026-10-28); gold validated (`fixtures/cases/gold_validation.csv`); not yet run  
**Milestone:** M2 follow-up  
**Label:** all numbers below are plans or come from earlier results files, which are cited.

---

## Question
On surfaces of near-duplicate tools, does accuracy depend on where the correct tool sits in the list?

## Why
EXP-001's confirmatory verdict (position effect absent) was dominated by goodserver at 100%. Its non-preregistered siblings follow-up at temperature 0 found a first-third advantage of +10.4 pp [+2.1, +19.8] for 120b and +13.5 pp [−1.0, +31.3] for 20b on 8 families (`results/exp001_siblings_t0_analysis.json`). This experiment tests that as a confirmatory hypothesis with enough families.

## Hypotheses
- **H1 (confirmatory):** On near-duplicate surfaces, accuracy is higher when the gold tool is in the first third of the list than the last third, for each model.
- **H2 (exploratory):** The effect is smaller for 120b than for 20b.

## Design

| Factor | Values |
|---|---|
| Surfaces | 4 new near-duplicate surfaces of 4 tools each: `nd_files`, `nd_messaging`, `nd_documents`, `nd_calendar` (`scripts/gen_followup_fixtures.py`). Tools have near-identical names and differ in one stated scope, so exactly one is right |
| Cases | `fixtures/cases/near_dup.jsonl`: 8 per surface, 2 per tool → **32 families**. Per tool, one case is worded neutrally and one uses a verb that matches a *different* tool's name, to test reading descriptions over names. Gold validated before any run (ADR-023) |
| Orderings | all 4! = 24 per surface |
| Models | `openai/gpt-oss-20b`, `openai/gpt-oss-120b` (Groq) |
| Temperature | 0 |

Total: 32 × 24 × 2 = **1,536 trials**, all new. The existing `siblings` surface is **not** reused for H1: its four tools are synonyms, so it has no correct answer (see the EXP-001 caveat). Its recorded temperature-0 data is reported separately as an exploratory tie-breaking measure, at no extra cost.

## Sample size
Scaling the EXP-001 follow-up's observed gap CI half-width (8.9 pp for 120b, 16.1 pp for 20b, 8 families) by √(8/n): 32 families gives about ±4.4 pp (120b) and ±8.1 pp (20b). Both would exclude zero at the effect sizes seen in the follow-up. These widths come from a synonym surface, so they are a proxy for the new surfaces [unverified]. "Absent" is reachable for 120b (if the true gap is 0, the upper bound lands near 4.4 pp, under 5) but not for 20b, whose verdict can only be confirmed or inconclusive. `scripts/power_sim.py` was not used: it simulates trials within a family as independent, which the siblings data contradicts (under 120b, s005 was right and s006 wrong in all 24 orderings), so it would understate the families needed.

## Primary outcome and analysis
Same as EXP-001 and `scripts/analyze_exp001.py`: gold position binned into thirds by `floor(3·index/4)` (positions {0,1}, {2}, {3}); gap = acc(first third) − acc(last third); clustered bootstrap over families, 10,000 resamples, seed 42. Reported per model, and per surface as exploratory.

## Verdict rule (per model)
- **position_effect_confirmed:** gap CI lower bound > 0.
- **position_effect_absent:** gap CI upper bound < 0.05.
- **inconclusive:** otherwise.

## Scoring
Answers are scored against the validated gold set; a tool judged acceptable in gold validation counts as correct. Refusals (`tool_use_failed`) are recorded and scored incorrect.
