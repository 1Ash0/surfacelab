# EXP-004 — Cross-Server Collision and Namespacing

**Status:** preregistered — not yet run  
**Milestone:** M4  
**Label:** [unverified] until data collected.

---

## Question
When servers are loaded together, which tool pairs steal each other's tasks, and does namespacing reduce that?

## Hypotheses
- **H1 (confirmatory):** Cross-server collision rate under `namespacing=none` is > 0.10.
- **H2 (confirmatory):** `prefix` namespacing reduces collision rate vs `none`.
- **H3 (confirmatory):** Pairwise description embedding cosine similarity is positively correlated with pairwise cross-server confusion rate (Spearman, permutation-test p).
- **H4 (exploratory):** `qualified` namespacing reduces collision further than `prefix`.

## Design

| Factor | Values |
|---|---|
| Merged surfaces | `merged_none`, `merged_prefix`, `merged_qualified` |
| Constituent servers | `goodserver` (5), `badserver` (5), `siblings` (4) → 14 tools total |
| Model | `openai/gpt-oss-20b` (Groq), `openai/gpt-oss-120b` (Groq) |
| Cases | `fixtures/cases/cross_server.jsonl` (12 families) |
| Variants | canonical order only |

Total: 12 × 3 surfaces × 2 models = **72 trials**

## Primary outcome
Cross-server collision rate = fraction of trials where the emitted tool belongs to a different server than the gold server. Per-surface CI (Wilson, since trials are independent across the three merge conditions for a given case).

## Predictive test (H3)
1. Embed all tool descriptions using `text-embedding-3-small` via OpenRouter (or Gemini embedding endpoint).
2. Compute 14×14 cosine similarity matrix.
3. For each off-diagonal pair (i, j from different servers), record confusion rate from the `none` condition.
4. Spearman ρ between similarity and confusion rate, permutation-test p (10,000 permutations). Pre-declared embedding model: first run uses OpenRouter `text-embedding-3-small`; replicated with a second model to check robustness.

## Multiple comparisons
H1, H2, H3 are confirmatory. H4 is exploratory.

## Surfaces (generated by scripts/gen_fixtures.py)
- `fixtures/surfaces/merged_none.json`
- `fixtures/surfaces/merged_prefix.json`
- `fixtures/surfaces/merged_qualified.json`

## Cases
`fixtures/cases/cross_server.jsonl` — gold is server-qualified (e.g. `goodserver/get_weather`). Grader uses qualified tool name for matched cases; unqualified comparison for the `none` condition.

## Analysis plan
1. Run all 72 trials.
2. For each trial, classify: hit (correct server + tool), cross-server-collision (wrong server), within-server-confusion (right server, wrong tool), miss (no call).
3. Compute collision rate per (surface, model).
4. Spearman ρ for H3 with permutation p.
5. Report McNemar for H2 (paired, matched on case).

## Verdict rule
- **H1 confirmed:** collision rate CI lower bound > 0.10 in `none` condition.
- **H2 confirmed:** collision rate in `prefix` significantly lower than `none` (McNemar p < 0.05, Holm-corrected).
