# EXP-008 — Does the 3D Sky Help? (Perception Check)

**Status:** preregistered 2026-10-29, before any participant; instrument live in the Observatory (chapter X) · **Label:** exploratory (ADR-020)  
**Decided by:** ADR-020 (reported either way), ADR-026 (retargeted to the real-server sky)

---

## Question
Can people find the tool that models called by mistake most often faster, or more accurately, using the 3D sky (stars and confusion threads) than using a plain table of the same counts?

## Design
- **Within-subject, two conditions:** *sky* (the Observatory's 3D view of one loadout, red threads weighted by recorded mistakes; answer by clicking a star) and *table* (a sortable-looking table of the same loadout's tools with "called first" and "of which wrong"; answer by clicking a row).
- **Two loadouts,** each with a single unambiguous answer in `docs/design/observatory-data.json`: *browser* (`list_pages`, 23 wrong first calls; next 4) and *docs* (`search_documentation`, 4; next 3). Web search and workspace are excluded because their top counts tie.
- **Counterbalancing:** task 1 is always browser and task 2 docs; the condition order (sky→table or table→sky) is assigned by a hash of the participant's opaque user id, so each person always gets the same order.
- **Measures per task:** correct (clicked the answer-key tool), time in milliseconds from the task appearing to the click.
- **Storage:** one document per participant at `exp008/<user id>`, holding condition order, the two trials, page version and timestamp. No names, no free text. Rules: each signed-in viewer can write and read only their own document; only the owner can read the collection.

## Participants and sample size
Peers invited by the project owner; target n = 10 (stop at 12). Not a random sample; results do not generalise beyond them.

## Analysis (fixed now)
- Accuracy: count right per condition, with exact McNemar on paired outcomes (descriptive at this n).
- Time: paired difference (sky − table) per person, median and a bootstrap 95% interval over participants (10,000 resamples, seed 42); also by order to check a learning effect.
- **Confound acknowledged:** the two loadouts differ in difficulty (browser's answer stands out more), so condition is crossed with loadout through the counterbalanced order. With n ≈ 10 this is reported, not modelled.

## Consequence rule (fixed now, ADR-020)
- If the sky is not faster or more accurate, the Tour keeps the sky but its copy stops implying the 3D view helps people read the data, and the table mode becomes the documented way to answer questions.
- Whatever the result, it is published in the plate archive and FINDINGS.
