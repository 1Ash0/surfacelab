# EXP-014 — Cross-Family Replication on Qwen

**Status:** preregistered and approved (2026-10-28, ADR-024); **run and analysed 2026-10-28**  
**Milestone:** validation  
**Label:** all numbers below are plans or come from earlier results files, which are cited.

---

## Question
Do the project's main findings hold for a model outside the gpt-oss family?

## Why
Every result so far uses `openai/gpt-oss-20b` and `-120b`, which share training. A finding that holds for only one family says little about tool surfaces in general. `qwen/qwen3.8-27b` is the only other chat model with tool calling on the Groq free tier (model list checked 2026-10-28).

## What is replicated (existing fixtures and runners, no new cases)

| Finding | Source | Rerun |
|---|---|---|
| Synonym tie-breaking: first-third advantage on `siblings` at T = 0 | `results/exp001_siblings_t0_analysis.json` (+10.4 pp for 120b) | `siblings`, 8 families × 24 orderings = 192 trials |
| Distinct scopes → no position effect, near-ceiling accuracy | `results/exp009_analysis.json` | EXP-009, 768 trials |
| Overlapping servers → almost no cross-server collisions | `results/exp011_analysis.json` | EXP-011, 144 trials |

Total **1,104 trials** on Qwen.

## Hypotheses (confirmatory, one per row)
- **R1:** On `siblings`, the first − last third gap has CI lower bound > 0.
- **R2:** On `nd_*`, accuracy ≥ 0.95 (clustered bootstrap CI lower bound).
- **R3:** On EXP-011 overlap surfaces, collision rate CI upper bound < 0.10 under `none`.

Analysis scripts are the ones used originally (`analyze_exp001.py --siblings-t0`, `analyze_exp009.py`, `analyze_followups.py --exp 11`), with the model list extended.

## Verdict rule
Each R is **replicated** if its condition holds, **not replicated** if the opposite bound holds (R1: upper < 0; R2: upper < 0.95; R3: lower > 0.10), otherwise **inconclusive**. A non-replication is reported with equal prominence.

## Results (2026-10-28)
Source: `results/exp014_analysis.json` (`scripts/analyze_exp014.py`, replay only). 1,104 Qwen trials, none left errored (EXP-009 pass 1 had 15 connection errors, re-sent in pass 2).

| Finding | Qwen result | Verdict |
|---|---|---|
| R1 synonym tie-breaking (`siblings`, T = 0) | accuracy 0.411; first minus last third gap +12.5 pp [+2.1, +25.0] | **replicated** |
| R2 distinct scopes, near ceiling (`nd_*`) | 768/768 correct, 0 refusals; CI [1.000, 1.000]; position gap +0.0 pp | **replicated** |
| R3 overlapping servers, few collisions (`none`) | 0 collisions in 48 trials, Wilson [0.000, 0.074]; 2 within-server errors | **replicated** |

**Interpretation.** All three findings hold for a model from a second family. The synonym first-position bias is if anything larger on Qwen (+12.5 pp against +10.4 pp for gpt-oss-120b in `results/exp001_siblings_t0_analysis.json`), and Qwen made no errors on the distinct-scope surfaces. This supports the project's central reading across both families tested: what decides tool choice is whether descriptions distinguish the tools, not order or namespacing.

## Deviations
- The R2 bootstrap CI is degenerate ([1, 1]) because every trial was correct; there is no variance to resample.
