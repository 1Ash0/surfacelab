# EXP-012 — Distractor Dose-Response on Near-Duplicate Surfaces (follow-up to EXP-005)

**Status:** preregistered and approved (2026-10-28); gold validated; **run and analysed 2026-10-28**  
**Milestone:** M6 follow-up  
**Label:** all numbers below are plans or come from earlier results files, which are cited.

---

## Question
When the surface is already hard, do extra distractors make it worse, and does it matter whether they are near-duplicates of the gold tool or unrelated?

## Why
EXP-005 padded goodserver with up to 50 distractors and accuracy stayed at 92–100% (`results/exp005_analysis.json`). Distractors rarely competed with five distinct tools. On near-duplicate surfaces (25–37% accurate), one more plausible tool may matter.

## Hypotheses
- **H1 (confirmatory):** Accuracy decreases as near-duplicate distractor count N rises from 0 to 20.
- **H2 (confirmatory):** At N = 10, the drop from N = 0 is larger for near-duplicate than for unrelated distractors.

## Design

| Factor | Values |
|---|---|
| Base surfaces | the 4 near-duplicate surfaces from EXP-009 |
| Distractor count N | 0, 2, 5, 10, 20 |
| Distractor kind | `unrelated` (existing `pad_surface` pool), `near-duplicate` (`fixtures/surfaces/distractors/nd_<name>.json`: 20 per surface, same domain, scopes no case asks for, e.g. "Search for files by name on a USB drive"; 10 scopes, each under two names) |
| Cases | the 32 families from EXP-009 |
| Orderings | canonical order for the base tools, distractors appended (as EXP-005) |
| Models | `openai/gpt-oss-20b`, `openai/gpt-oss-120b` |
| Temperature | 0 |

Total: 32 × (1 shared N = 0 + 4 N-values × 2 kinds) × 2 models = **576 trials**.

## Floor check
EXP-009 canonical-order accuracy was ≥ 0.99 for both models (`results/exp009_analysis.json`), well above 0.15; EXP-012 ran.

## Results (2026-10-28)

Source: `results/exp012_analysis.json` (`scripts/analyze_followups.py --exp 12`); 288 trials per model, 0 errors.

| Model | Kind | Acc. N=0 / 2 / 5 / 10 / 20 | Slope per 10 | Drop N0−N20 [95% CI] |
|---|---|---|---|---|
| 20b | unrelated | 1.000 / 1.000 / 1.000 / 1.000 / 0.969 | not estimable | +3.1 pp [+0.0, +9.4] |
| 20b | near-duplicate | 1.000 / 1.000 / 1.000 / 1.000 / 1.000 | not estimable | +0.0 pp [+0.0, +0.0] |
| 120b | unrelated | 1.000 / 1.000 / 1.000 / 1.000 / 0.938 | not estimable | +6.2 pp [+0.0, +15.6] |
| 120b | near-duplicate | 1.000 / 1.000 / 1.000 / 0.969 / 0.969 | not estimable | +3.1 pp [+0.0, +9.4] |

**Verdicts.** H1 not confirmed: the logistic slope was not estimable (near-perfect separation in over 10% of resamples), and the fallback N=0 − N=20 drop for near-duplicates has CI lower bound 0.0 for both models. H2 not confirmed: drop(near-duplicate) − drop(unrelated) at N = 10 is 20b +0.0 pp [+0.0, +0.0], 120b +3.1 pp [+0.0, +9.4], lower bounds below 0.05.

**Interpretation.** Up to 20 same-domain distractors with out-of-scope descriptions barely moved accuracy (at most 2 of 32 wrong in any cell). As with EXP-005, distractors whose descriptions rule themselves out do not compete.

## Deviations
- Near-duplicate distractors are the first N tools of `fixtures/surfaces/distractors/nd_<surface>.json` in file order; unrelated ones come from `pad_surface(..., seed=42)`.
- The N = 0 trials are shared by both kinds, as designed (one shared N = 0).
