Coda · What it means

Tools fail where their descriptions blur together.

Write tools that read differently. With one clear job per tool, order, wording and extra tools barely mattered (chapter II). Misses on real servers landed on look-alikes (chapter IV).
Test the servers people install together. Hand-written surfaces scored 99%+; real loadouts dropped gpt-oss to 77–78% on requests only one tool could serve.
Watch the first action, not just the answer. Which server handles a shared job is a model habit; list order moved it in only 19–25% of shared requests.
