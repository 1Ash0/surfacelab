# ROADMAP

Two tracks run in lockstep. **Track L** (Lab + tool) produces measurements. **Track W** (Observatory) turns each into a scene as soon as its data exists. A milestone is done only when both its L and W exit criteria are met. Hard rule: **no scene ships on simulated data without the permanent `simulated` badge** (DESIGN §1).

Time estimates are deliberately absent; gates and exit criteria decide pace.

## M0 Verify and bootstrap
**L:** `make check` green; PRIOR_ART verification tasks done (all `[read-summary]`/`[snippet]`/`[secondhand]` entries upgraded or flagged before quoting); ADR-003 (consume toolgauge case format?) and ADR-009 (name) decided.
**W:** scaffold `web/` (static export, strict TS); **engine spike**: instanced points with GPU picking, orbit camera, quality-tier switch and context-loss recovery on a fixture surface; **look-test** of Dusk vs Daylight stage, display-font candidates and the six server hues on a real phone (checks in DESIGN §2); decide ADR-016 (three.js vanilla) and the default stage (ADR-017).
**Exit:** spike runs at the `medium` tier on a real phone, with the measured frame time written to the notebook.
**Gate:** G0 (MCP, rendering, token ledger) starts here.

## M1 Harness, fixtures, cassettes
**L:** `surfacelab inspect` prints a surface with the token ledger; grader two-sided tests; dry-run works; budget guard.
**W:** **S1 Request Anatomy** on real fixture surfaces (no model calls needed), with evidence rail, table/describe modes, URL state. Types generated from schema.
**Exit:** a stranger can drop a fixture surface into `/bench` and see where its tokens go.

## M2 Order probe (v0.1 release)
**L:** EXP-001 runs; report with clustered intervals; v0.1 on PyPI (if ADR-009 clean); results page.
**W:** **S3 Shuffle Rack** with position ghost strip; **S2 Galaxy v0** (similarity only, labelled); OG cards; evidence rail complete.
**Exit:** one real, quotable finding with an interval, shown as a scene; EXP-001 post kit generated by `make posts`.
**Release rule:** v0.1 ships when this is true, not when everything is built.

## M3 Paraphrase and edits
**L:** EXP-002 and EXP-003; per-edit verdict ladder; held-out family split in code.
**W:** **S6 Edit Migration**; verdict chips in rail; edit ladder (flat).
**Exit:** one edit shown to help, cost or regress, with accuracy and token deltas.

## M4 Cross-server collisions
**L:** EXP-004; Spearman with permutation p; repeat with a second embedding.
**W:** **Galaxy v1** (measured confusion edges); **S4 Merge Collider** with namespacing arms; deterministic worker layout.
**Exit:** Galaxy and Merge Collider interactive on a phone; collision matrix fallback verified.

## M5 Pulse and adoption
**L:** Pulse (sandboxed; start-rate; drift classifier; EXP-007 precision/recall); GitHub Action fails on regression.
**W:** **S7 Pulse Ribbons**; `<surfacelab-galaxy>` web component; PR comment still; badges; Pages publishing.
**Exit:** an external repo runs the Action and the embed works in a third-party page; sandbox review done.

## M6 Dose-response
**L:** EXP-005 crossed design (count × distractor kind × arm), tokens-per-call.
**W:** **S5 Selection Rain** with sliders; per-cell n and interval in rail.
**Exit:** the crossed figure with intervals, reproducible from `results/`.

## M7 The Tour, capture, launch
**L:** EXP-006/007 as warranted; Atlan outreach artifact (public surface only, measurement frame).
**W:** **The Tour** (scroll-driven, five chapters, rails authored as data); deterministic capture mode and video kit; performance and accessibility pass; visual regression suite; **EXP-008 perception check** run with peers.
**Exit:** the landing page holds up on a mid-range phone, with the fallback verified; every number on the page traces to a result file.

## Later (each needs an evidence trigger and an ADR)
Gateway/proxy mode; WebGPU path; in-browser embedding for The Bench; VR/WebXR (no); more probes; multi-model comparison page; a public "surface registry" of measured servers (only with a consent and takedown policy).

## Scope fence
Not a linter, not a fixed-set eval, not a security scanner, not a hosted service. No scene decorates. No claim without a result file.

## Definition of done (any milestone)
`make check` green; docs updated; ledger and notebook updated; decisions recorded; scene fallback verified; evidence rail complete; tags correct; a human has looked at the scene on a phone.
